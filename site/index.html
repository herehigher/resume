履歴書・職務経歴書を、この端末で作成

Resume Studio は、ブラウザ上で書類を編集し、プレビューを確認してPDFまたはJSONで書き出せるアプリです。まず使用する言語を選んでください。

言語を選択

日本語、简体中文、English の紹介ページから、対応する editor を開けます。

PDF と JSON

ブラウザの印刷機能でPDFとして保存できます。JSONの書き出しと読み込みで、この端末上の下書きをバックアップ・復元できます。

プライバシー

アプリは履歴書データをアップロードしません。書き出したPDFやJSONには個人情報が含まれる場合があります。
