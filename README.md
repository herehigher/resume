# Resume Studio

日本語の履歴書・職務経歴書をブラウザ上で作成する、個人利用向けのWebアプリです。

外部サービスやサーバーを使わず、入力・保存・PDF出力までローカル環境で完結します。

## 使い方

1. `index.html` をChromeなどのブラウザで開く
2. 左側のフォームへ情報を入力する
3. 右側のプレビューで仕上がりを確認する
4. 「PDF出力」から印刷画面を開き、「PDFとして保存」を選択する

ローカルサーバーやパッケージのインストールは不要です。

## 主な機能

- 履歴書・職務経歴書の切り替え
- 入力内容のリアルタイムプレビュー
- 学歴・職歴・資格・勤務先の追加と削除
- GitHub URLの掲載
- Credlyなど、資格確認URLの掲載
- 証明写真の登録と自動トリミング
- 入力途中の自動保存、手動保存、再読み込み
- A4用紙に最適化したPDF出力
- スマートフォン向け表示

## データとプライバシー

- 入力情報は外部へ送信されません。
- 下書きはブラウザのローカルストレージへ保存されます。
- ブラウザのデータを消去すると、保存した下書きも削除されます。
- 別のブラウザや端末へ下書きは自動同期されません。
- 共有PCで利用する場合は、作業後に「入力内容をすべて消去」を実行してください。

## ファイル構成

```text
resume/
├── index.html   # 配布・利用用の単一HTMLファイル
├── styles.css   # 編集用スタイルソース
├── app.js       # 編集用JavaScriptソース
├── README.md    # 利用案内
└── AGENTS.md    # 開発規約
```

`index.html` にはCSSとJavaScriptを内蔵しています。通常利用では `index.html` 単体で動作します。

## 開発時の注意

`styles.css` または `app.js` を変更した場合は、同じ内容を `index.html` 内の `<style>`・`<script>` にも反映してください。詳しい規約と確認項目は `AGENTS.md` に記載しています。

## 対応環境

最新版のGoogle Chromeを推奨します。PDFの仕上がりは印刷プレビューで確認してください。
