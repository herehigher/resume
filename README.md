# Resume Studio

日本語の履歴書・職務経歴書をブラウザ上で作成する、個人利用向けのWebアプリです。

外部サービスやサーバーを使わず、入力・保存・PDF出力までローカル環境で完結します。

## 使い方

1. `index.html` をChromeなどのブラウザで開く
2. 左側のフォームへ情報を入力する
3. 右側のプレビューで仕上がりを確認する
4. 「PDF出力」から印刷画面を開き、「PDFとして保存」を選択する

ローカルサーバーやパッケージのインストールは不要です。

## 主な機能

- 履歴書・職務経歴書の切り替え
- 入力内容のリアルタイムプレビュー
- 学歴・職歴・資格・勤務先の追加と削除
- GitHub URLの掲載
- Credlyなど、資格確認URLの掲載
- 証明写真の登録と自動トリミング
- 入力途中の自動保存、手動保存、再読み込み
- 保存済み下書きを変更しない入力例の一時表示
- A4用紙に最適化したPDF出力
- スマートフォン向け表示

## データとプライバシー

- 入力情報は外部へ送信されません。
- 下書きはブラウザのローカルストレージへ保存されます。
- ブラウザのデータを消去すると、保存した下書きも削除されます。
- 別のブラウザや端末へ下書きは自動同期されません。
- 共有PCで利用する場合は、作業後に「入力内容をすべて消去」を実行してください。

## 下書き保存仕様

- 保存方式: ブラウザの `localStorage`
- 保存キー: `resume-studio-data-v1`
- 保存内容: 基本情報、連絡先、学歴、職歴、資格、職務経歴、証明写真、編集中の書類
- 証明写真: サイズを調整した画像をBase64形式で保存
- 自動保存: 入力後約300ミリ秒で保存
- 手動保存: 「下書きを保存」を押した時点で即時保存
- 再読み込み: 「保存内容を再読込」またはページを開き直したときに復元
- 終了時保存: ページ更新やタブを閉じる直前にも保存を確定
- 下書き削除: 「保存した下書きを削除」から確認画面に同意した場合のみ削除
- 入力例: 一時表示中は自動保存せず、「元の下書きに戻る」または「この例を下書きとして使用」を選択

保存領域はブラウザとプロフィールごとに分かれます。`file://` で開く場合は、同じブラウザプロフィールと同じ `index.html` のパスを使用してください。

保存データはプロジェクトフォルダやGitリポジトリには作成されません。Chromeではプロフィール内のLocal Storage領域へ内部データとして保存されます。

現在、下書きのJSON書き出し・読み込みや、別端末への同期機能はありません。ブラウザのデータ消去、プロフィール削除、保存元ファイルの移動などに備えた外部バックアップは未対応です。

下書きを削除すると、ローカルストレージの保存キー自体が削除されます。削除後に新しく入力または手動保存するまでは、空の下書きを自動で作成しません。

## ファイル構成

```text
resume/
├── index.html   # 配布・利用用の単一HTMLファイル
├── styles.css   # 編集用スタイルソース
├── app.js       # 編集用JavaScriptソース
├── README.md    # 利用案内
└── AGENTS.md    # 開発規約
```

`index.html` にはCSSとJavaScriptを内蔵しています。通常利用では `index.html` 単体で動作します。

## 開発時の注意

`styles.css` または `app.js` を変更した場合は、同じ内容を `index.html` 内の `<style>`・`<script>` にも反映してください。詳しい規約と確認項目は `AGENTS.md` に記載しています。

## 対応環境

最新版のGoogle Chromeを推奨します。PDFの仕上がりは印刷プレビューで確認してください。
